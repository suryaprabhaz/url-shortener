# Linkly - URL Shortener

This is a simple, static URL shortener built with Next.js.

## Project Structure

- `frontend/`: The main application code (Next.js 14, Tailwind CSS).

## How to Run

1. `cd frontend`
2. `npm install`
3. `npm run dev`
